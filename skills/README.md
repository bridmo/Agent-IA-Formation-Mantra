# Index des skills

68 machines réutilisables. Une méthode écrite une fois, rejouée à chaque fois.

**Légende :** 🔧 = calibration à faire avant le premier usage (section « Calibration » en tête du fichier).
Les autres marchent tels quels.

**Important :** un skill n'est découvrable que s'il est lié dans `.claude/skills/`. N'activez que ceux
que vous utilisez : soixante-huit descriptions à évaluer à chaque tour, ça ralentit et ça brouille le
déclenchement. Voir [.claude/README.md](../.claude/README.md).

Comment en écrire un, comment en calibrer un : [docs/SKILLS.md](../docs/SKILLS.md).
