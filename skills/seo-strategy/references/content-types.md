# Content types — seo-strategy references

Les 7 types d'articles qui marchent sur le marché FR 2025-2026, avec leur pattern de titre, quand les utiliser, le pont produit associé, et des exemples concurrents positionnés. Chargé à la demande par `seo-strategy` Phase 5 "Filtre 3 : Choisir le type de contenu".

## Règle

Basé sur l'analyse SERP et les patterns concurrents prouvés, choisir parmi ces 7 types. Si le SERP montre un format dominant, suivre ce format. Si le SERP est mixte, privilégier le type qui correspond le mieux à l'intent du keyword.

⛔ **Règle anti-tool-first :** le choix du type se fait **par keyword, sur base SERP**, pas "1 type par cluster dans l'abstrait". Un même cluster JTBD contient typiquement plusieurs types (1 pillar long + 2-4 guides outils + 2-4 comparatifs courts).

## Les 7 types

| Type | Pattern de titre | Quand l'utiliser | Pont vers le produit | Exemples concurrents |
|---|---|---|---|---|
| **Tutoriel outil** | `[Outil] : guide complet [usage]` / `[Outil] : Guide, Présentation & Avis` | Keyword = nom d'un outil enseigné dans la formation | Pont outil : "On enseigne cet outil dans notre formation" | DataBird : "Fonction RECHERCHEV Excel" (1 723/mo), École Cube : "Google AI Studio : Guide & Avis" (9 376/mo) |
| **Comparatif outils** | `[A] vs [B] : quel [catégorie] choisir en [année] ?` / `[Outil] : gratuit ou payant ?` | Keywords "vs", "gratuit", "alternative" | Pont outil : "On t'apprend à choisir et maîtriser le bon outil" | Lion : "ChatGPT gratuit ou payant ?" (4 705/mo), "Gemini vs ChatGPT" (1 030/mo) |
| **Comparatif formations** | `Les [N] meilleures formations [discipline] en [année]` | Keywords "formation X", "meilleure formation X" | Pont direct : {{COMPANY}} est dans le comparatif | {{COMPANY}} : "5 meilleures formations growth hacking" (179/mo, pos 1-4) |
| **Listicle outils** | `[N] outils [catégorie] pour [usage/métier] en [année]` / `[N] alternatives à [X]` | Keywords "meilleur outil", "outils pour", "alternative" | Pont outil : les outils listés sont enseignés | Lion : "10 alternatives IA à PowerPoint" (148/mo), DataBird : "10 outils pour data analyst" (646/mo) |
| **Fiche métier** | `[Métier] : fiche métier, salaire et compétences [année]` | Keywords "[métier]", "[métier] salaire", "devenir [métier]" | Pont carrière : "On forme à ce métier" | DataBird : "data analyst", "analytics engineer". Lion : "COO" (318/mo), "AI Product Manager" (48/mo) |
| **Guide pratique** | `Comment [action] avec [outil/méthode]` / `[N] [choses] à [action] avec [outil]` | Keywords d'action ("automatiser", "créer", "utiliser") | Pont outil : "On enseigne cette compétence" | DataBird : "Utiliser Power Query" (1 182/mo). Lion : "Automatiser prospection LinkedIn" (30/mo, pos 1) |
| **Définition** | `[Concept] : qu'est-ce que c'est ?` / `[Concept] : définition et guide [année]` | Keywords définitionnels, concepts émergents | Pont audience : TOFU, CTA indirect | École Cube : "Data c'est quoi" (162/mo). Lion : "Culture fit" (45/mo) |

## Pattern cluster JTBD

Dans un cluster JTBD correctement équilibré :
- **1 pillar long-form** (2 000+ mots) qui couvre le job de bout en bout — pattern "Guide méthode" ou "Pillar"
- **2-4 guides outils moyens** (1 200-2 000 mots) — pattern "Tutoriel outil" ou "Feature guide"
- **2-4 short-form courts** (800-1 200 mots) — pattern "Comparatif outils", "Définition", "Fiche métier"
