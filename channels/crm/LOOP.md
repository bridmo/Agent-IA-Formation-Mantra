# ⟳ Boucle CRM

Collecte quotidienne (formulaires, publicité, import) → Réconciliation vers le CRM avec la source → Contrôle de complétude (combien sans source ?) → Alerte si écart → Séquence de cycle de vie → **GATE : tout envoi validé** → Mesure (ouverture, réponse, clients) → Apprentissage en mémoire.

## Le contrôle qui compte
Quelle part de vos clients gagnés n'a aucune source identifiée ? Tant que ce chiffre dépasse 20 %, tous vos arbitrages entre canaux sont des paris.
