# .scratch/ — jetable

Tout ce qui ne mérite pas d'être versionné : brouillons, exports temporaires, essais, sorties intermédiaires.

Ce dossier est dans le `.gitignore`. Rien de ce que vous mettez ici ne partira sur GitHub, ce qui en fait aussi le bon endroit pour un export contenant des données personnelles le temps d'un travail.

Videz-le quand vous voulez. Si un fichier d'ici commence à compter, c'est qu'il doit déménager dans une cellule ou dans `brain/`.
